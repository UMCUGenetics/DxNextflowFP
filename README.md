# DxNextflowFP
Repo with scripts to process fingerprint data.

## Install nf-core and Nextflow

```
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install nf-core

curl -s https://get.nextflow.io | bash
mv nextflow venv/bin/
```
